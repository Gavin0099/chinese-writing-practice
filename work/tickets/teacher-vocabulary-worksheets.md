# 老師指定詞庫與詞語測驗卷

首版要讓家長在自己的班級詞庫存入老師指定的詞語，確認詞語、完整注音與課次，再選第一至第八課抽 15 題，印出 A4 考卷與解答。V-01～V-03 接在國字查詢 MVP 之後。

| Slice | 優先度 | 範圍與驗收 |
| --- | --- | --- |
| V-01 | P0 | 每筆詞語有班級識別碼、學年度、出版社、教材版次、年級、學期、課次、目標生字、完整詞語、逐字注音及確認狀態。同一字可對應多詞。兩個班使用同教材時，各自只查到自己的詞庫。 |
| V-02 | P0 | 支援手動輸入、批次貼上、修改及刪除。貼上後先預覽逐字注音及挖空字，指出重複與缺欄項目。家長可批次確認已填寫的注音。編輯詞語或注音後需重新確認。 |
| V-03 | P0 | 選班級、課次範圍、題數及選填種子，從已確認詞語不放回抽樣。考卷只挖空指定字，保留其他字及完整直式注音。題目快照和答卷共用相同題序。候選不足時提示可出的題數，讓家長調整。 |
| V-04 | P1 | 共用 OCR 擷取文字，對圈選或螢光筆標記提供候選，保留原圖供家長對照。手寫重疊或圈選範圍不明時允許修正。只有已確認的項目入詞庫。 |
| V-05 | P1 | 用該孩子確認的錯詞紀錄優先抽題，支援跨課複習及同卷去重。班級詞庫可共用於同班孩子，各自保有錯詞優先順序。 |
| V-06 | P2 | 家長可自願匯出、匯入或分享詞庫。匯入時預覽版次、班級、衝突和來源，確認後才套用。分享檔只包含選取的詞庫項目。 |

## 資料與驗收邊界

- 官方教材提供習寫字、認讀字與課次。老師詞庫保存班級指定詞語。個人學習紀錄保存孩子的錯詞及熟練度。老師詞庫的內容變動不影響官方資料或其他班級。
- 注音按整個詞語核對。含多音字的詞語須確認各字的語境讀音，確認前不進題庫。
- 班級詞庫、原圖與孩子紀錄預設私人。首版使用本機資料，V-06 的分享檔不含原圖或孩子紀錄。匯入教材詞語仍依各來源確認使用範圍。
- 以兩個同教材班級、重複詞、多音字、未確認詞、指定題數不足及同名課次跨學年度為回歸案例。實際列印需核對試卷與解答題序一致，以及 A4 題幹、田字格與注音未裁切。
- V-03 正式交付前，依 [列印工單](2026-02-03-stabilize-print.md) 修復既有空白頁並驗證 Windows 實際列印。

## 操作與驗收

1. 開啟「老師詞庫與出卷」，建立 115 學年度、康軒、二年級上學期的班級詞庫。可直接手動建檔。
2. 輸入詞語、逐字注音、課次，勾選要挖空的字並確認注音。也可從試算表貼上詞語、注音、挖空位置三欄，預覽後儲存。只有詞語時，可先存為待補注音。
3. 選第 1～8 課及 15 題。固定種子與相同題庫會重現題序，種子留空會重新抽題。跨課相同題面合併，快照保留來源課次與原詞條識別碼。同題面可能對到不同答案時排除並提示。
4. 從「已儲存的考卷」開啟，可單獨列印考卷或解答，也可一起印。已儲存的考卷使用當次題目快照，之後修改詞語不會改變原考卷。

2026-11-11 以 Windows Chrome 完成兩班詞庫、同詞跨課、30 抽 15、10 題不足、固定及新種子、重開後重印的驗收。使用 Microsoft Print to PDF 實際提交 Windows 列印工作，輸出兩頁 A4，核對田字格、注音、頁尾與題序。另以 16 個 10 字長詞驗證考卷與解答各兩頁、題號連續、內容在 A4 列印範圍內。紙本列印和 iPhone Safari 實機輸入、保存、重開及操作待驗。Chrome 手機尺寸已驗證手動新增、非首字挖空和重開保留。
