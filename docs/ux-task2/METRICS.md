- 環境：Linux Chromium（Google Chrome for Linux，Playwright），viewport 390×844（isMobile + touch）與 1280×800。**Windows Chrome：NOT MEASURED（Linux Chromium 替代）。iPhone Safari：NOT MEASURED。實體列印：NOT MEASURED。**
- 資料：`node scripts/create-ux-review-fixtures.mjs` 的合成備份還原後的 localStorage（有詞庫）；空詞庫＝只有設定、無詞庫；首次使用＝全新 profile。雲端未設定（沒有 Supabase 連線），所以「已登入／未登入」的真實雲端狀態 **NOT MEASURED**，本表只量測「本機／未設定」文案。
- 互動目標：可見的 a[href]／button／input／select／textarea／summary／[role=button]，checkbox／radio 取其 label；寬或高 <43.5px 算小。skip-link 與頁尾授權連結（19px）也會被算入。

- 列印閘門：考卷（兩頁／只看考卷／只看解答，固定種子 `fixed-seed-1`，A4）與練習簿（3 頁，A4）用 `page.pdf` print 媒體產生，`pdftoppm -r 100` 後逐像素與 base 比對。比對腳本的反向測試（只看解答 vs 只看考卷）會報出 48,490 個不同像素。因為 B 把「亂數種子」收進摺疊的進階區，閘門腳本（三組同一支）在填種子前會先展開該區。
