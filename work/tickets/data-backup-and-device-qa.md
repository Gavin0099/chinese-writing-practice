# 資料備份與實機驗收

從「老師詞庫與出卷」或「國字學習查詢」開啟「備份與還原」。下載的 JSON 包含班級、詞語、逐字注音、課次、挖空位置、考卷快照、已確認教學進度及習寫歷程。教材檔另行保留，重新匯入相同版本即可繼續查詢。

還原前顯示筆數。已有資料時需確認取代，可以先下載目前的備份。程式驗證備份版本與資料內容後才寫入，遇到儲存失敗會嘗試復原已變更的欄位。備份僅在目前瀏覽器讀寫。

2026-11-11 Windows Chrome 下載功能驗收班備份、清除測試網站資料、還原並重新開啟。30 筆詞語及原考卷、教學進度和習寫歷程逐筆相同。另一個 Chrome 手機尺寸測試環境也可還原。實機驗收用合成備份位於 `artifacts/runtime/curriculum-115/p-qa-01-sample-backup.json`。

## P-QA-01 實機步驟

1. 在 iPhone Safari 開啟可由該手機存取的 HTTPS 驗收站。匯入合成備份，新增第八課詞語及注音，選擇挖空字，確認注音後關閉分頁。重新開啟核對詞語、注音及原考卷均保留。
2. 在 Windows 開啟同一份測試詞庫與考卷。選實體印表機、A4、實際大小，列印考卷及解答。核對無空白頁、題序與挖空相符，右側直式注音、田字格和頁尾完整。
3. 記錄 iOS 版本、Safari 操作結果、Windows 印表機型號及紙本頁數。Windows 目前的清單只有 Microsoft Print to PDF 與 OneNote，本輪尚未取得紙本或實機 Safari 證據。

## OCR-01／V-04 真實圈詞驗收

使用家長同意的真實老師圈詞作業，先記錄手動建完該課詞庫花費的時間。再用 iPhone 拍照，記錄候選詞、辨識錯詞、誤抓及漏掉的圈選、人工修正次數和完成時間。家長確認候選國字、圈選範圍及逐字注音後，才可寫入指定班級課次。最後用 Windows 開啟該家庭詞庫並出卷。原圖留在授權的驗收環境，公開工單僅記錄結果。
