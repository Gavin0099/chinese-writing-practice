# 開發流程與專案事實

## 專案事實

- 網站入口是 `index.html`，由 HTML、CSS 與瀏覽器 JavaScript 產生中文練習紙。專案使用 Cloudflare Pages 靜態部署。
- `data_engineering/` 存放教材來源與資料處理工具，瀏覽器入口載入已生成的資料檔。
- [專案簡介](00_project_brief.md)、[限制](01_constraints.md)、[架構](04_architecture.md)及[品質標準](07_quality_bar.md)維持原有文件入口。

## 導入後的工作方式

- 工單與階段產出繼續放在 `work/tickets/` 與 `work/outputs/`。依 `AGENTS.md` 按需取得上下文。
- 框架由 Git submodule 固定版本。新 clone 安裝及驗證見 [AI Governance 導入指南](../docs/GOVERNANCE_ONBOARDING.md)。
- Owner 於 2026-11-11 確認中文書寫練習與列印教材生成屬低風險。各工單按變更內容決定驗收範圍。
- 國字查詢依教材版本讀取家長確認的進度。練習紙輸出紀錄供首頁推薦。老師指定詞庫規劃依班級與教材版次獨立儲存，孩子的習寫和錯詞另存於個人紀錄。開發順序與驗收條件見 [PLAN](../PLAN.md)。
- 115 上查詢驗收由家長選取本機教材檔，僅將來源比對一致的編號課次供同瀏覽器查詢。教學進度與習寫紀錄各自儲存。公開教材接入仍依 D-04 授權與 D-05 的驗證條件處理。
- 老師詞庫按班級和課次儲存，家長確認逐字注音後才可出題。考卷快照保存當次題序、來源、注音和挖空位置，考卷與解答共用同一份題目資料。
- 備份與雲端同步共用版本化資料格式，涵蓋詞庫、考卷快照、確認過的教學進度和習寫紀錄。教材另由各裝置匯入。雲端首版以帳號分隔家庭資料，每筆寫入以資料庫版本防止舊裝置覆蓋。IndexedDB 離線能力列入 DB-04。
- 家庭與孩子使用獨立識別碼。首版備份對應家庭的主要孩子。首次上傳保留雲端的既有資料，同一份匯入可安全重試。版本衝突時，使用者可下載本次修改的備份，再重新載入核對。
- Google 登入用 Supabase PKCE 及身份連結。家庭歸屬沿用 Auth 使用者 ID。手動連結由登入者確認並核對回呼的使用者 ID。已驗證 Email 的自動連結由 Supabase 處理。Email 驗證碼在本機測試介面使用，正式備援列入 AUTH-06。
