# 探索問題與本輪假設

本輪為非互動實驗，不等待回答、不要求 Gavin 指定顏色或色碼。以下八題依需求與程式碼作答；「假設」尚未經 Gavin 確認。

| 問題 | 本輪答案 | 依據 |
| --- | --- | --- |
| 1. 這次要解決什麼不滿意？ | 排版已接受，改善首頁的配色與視覺感受；先展示多種方向。 | Owner 明確回饋 |
| 2. 誰在什麼情境、裝置使用？ | 台灣國小家長與老師，主要手機、兼顧桌面；整理詞庫、出考卷、製作練習紙。 | 使用者提供的產品脈絡 |
| 3. 希望給人的三種感覺？ | 假設「清楚、可信、親切」。六版分別強調效率、溫柔、輕盈、書卷、活力、沉靜，不預選勝出方向。 | 成人操作教學工具的情境推論 |
| 4. 有喜歡的參考圖或網站嗎？ | 未提供。只使用專案程式碼與兩份本地技能的資料，不瀏覽外站、不引入參考圖片。 | 沒有額外參考；限定工作目錄 |
| 5. 可以沿用哪些熟悉的結構？ | 固定現有導覽、老師詞庫入口、推薦練習紙、自訂設定與頁尾；所有方向共用同一份 HTML 與幾何 CSS。 | index.html、styles.css、script.js |
| 6. 有什麼不能動？ | 全部產品檔案、測試、列印與 A4、考卷與解答、田字格、描紅、筆順 SVG、資料契約、抽題／種子、注音／挖空、Auth／RLS／備份／同步。只寫 design-exploration/。 | 使用者 HARD RULES 與 PROTECTED |
| 7. 明確不喜歡什麼？ | 不再提出綠色方向；現況基準為忠實對照而保留綠色。沒有推論 Gavin 喜歡或討厭其他特定色相。 | 前兩輪綠色方案皆不喜歡 |
| 8. 是否有品牌字型、色票或狀態需沿用？ | 沒有指定新色票或品牌字型。假設比較「已完成首次設定、課程已載入、未產生輸出」首頁；固定 1 年級上學期、第 1 課「拍拍手」。只用系統字型，不載入 Google Fonts／其他字型檔。 | task 限制；script.js 的標題與按鈕內容；curriculum_data.js 的現有課名 |

補充假設：

- 本輪不探索首次設定、筆順提示、輸出成功或展開的自訂面板。它們需要後續套色驗證，但不是變更版面的理由。
- 既有 emoji、文案、順序、標題尺寸、留白與圓角均保留。字重、字距、字型 fallback 可因方向不同而改變字感；不同裝置可能有不同折行。
- 「夜讀靛藍」只是第六個完整方向，不代表新增切換器或偏好儲存。
- 色彩對比計算只涵蓋指定字色配對；沒有推論成完整無障礙通過、較快出卷或較高使用率。
- 後續選擇可以是「02 整體、01 按鈕」等自然描述。未選定前不實作，不覆蓋 R0／R1。
