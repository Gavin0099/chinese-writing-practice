# QA Testcases & Risk Assessment

## 測試案例

### TC01: Chrome 桌機列印預覽
- **步驟**: 在 Chrome 開啟練習簿 -> 生成 -> Ctrl + P。
- **預期結果**: 僅顯示 A4 內容，不顯示頂部導覽列、底部來源說明或 Smart Card。

### TC02: iOS Safari PDF 導出
- **步驟**: 在 iPhone Safari 開啟 -> 生成 -> 分享 -> 列印 -> 雙指展開預覽。
- **預期結果**: PDF 頂部不應出現「生字練習簿產生器」或網址。

### TC03: 多頁連續性
- **步驟**: 輸入超過一頁數量的生字 -> 列印。
- **預期結果**: 第二頁版面與第一頁完全一致，無垂直位移或裁切。

## 風險評估 (Risk.md)
- **邊距溢出**: 部分印表機有物理不列印區，若 `285mm` 仍太高，可能需要降至 `280mm`。
- **字型加載**: 若網路不穩導致 `@font-face` 未加載完成即列印，筆畫可能顯示為細體。
