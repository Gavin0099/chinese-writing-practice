# UX 改善任務 2：改版與驗證計畫

日期：2026-11-12。基準：`901cb8d`。本文件回應 [ISSUES.md](ISSUES.md) 的 U1–U8，**只提出第二階段方案，沒有實作**。目前只新增這兩份文件；不建立 `PRODUCT.md`、`DESIGN.md` 或第三份報告。

## 方向與判斷邊界

讓家長先辨認正在操作的班級及保存位置，再選「輸入老師詞語」或「使用已有詞庫出卷」。初次使用引導到第一份有效詞庫；回訪讓出卷與重開考卷先於長表單。保留產品既有字型、顏色與校園用語；不以換配色、增加插圖或建立新設計系統作為解法。

採 Operate 模式：優先任務次序、可預期的表單及清楚回饋。390px 使用可順讀的單欄；1280px 可把輸入與清單並列，但兩尺寸共用相同資訊架構及 DOM 順序。沒有畫面證據前，不指定新視覺風格、導覽抽屜、固定底列或動畫。

本次無法渲染或操作瀏覽器。所有 after 線框是**提案**，before 是**來源結構描述**；兩者皆不是截圖。確切尺寸、首屏容納量、對比及鍵盤流程仍需實測。開始 UI 修改前，先補基準畫面，避免把推論當缺陷全面重做。

## 390×844 的 before／after 文字配置

以下每組 before 都是來源順序，畫面實況 **NOT OBSERVED**；after 是設計目標，未實作、未量測。箭頭代表閱讀／操作順序，不代表實測點擊次數。

### 首頁：首次與回訪

```text
BEFORE 首次：歡迎／練習紙說明 → 六年級選項 → 學期 → 開始練習
             → 國字查詢連結／老師詞庫連結
BEFORE 回訪：品牌＋工具連結（可折行）→ 推薦練習紙 → 自訂設定

AFTER 首次：歡迎／可直接開始老師詞庫
             [老師詞庫與出卷] → 國字查詢
             製作練習紙：既有年級／學期／開始操作
AFTER 回訪：精簡品牌／導覽（保留查詢與資料保存入口）
             老師指定詞語
             [老師詞庫與出卷]  新增、貼上或從既有詞庫出卷
             原推薦練習紙／原自訂設定
```

老師詞庫入口不用填年級、不用登入；兩條本來可用的路徑只是更明顯。保留原 worksheet 控制與祖先 DOM，不把預覽搬進新 wrapper。

### 詞庫：沒有班級／已有空班級

```text
BEFORE 無班級：工具列 → 標題／本機說明 → 空 select → 建班 details 展開
               名稱／出版社／學年度／年級／學期／版次／建立
BEFORE 空班級：班級 → 出卷捷徑 → 單筆完整表單 → 批次收合
               →「這裡還沒有詞語」→ 出卷 0 題、預設抽 15 題

AFTER 無班級：工具列 → 老師詞庫 → 實際資料來源
               先建立班級，集中保存老師指定詞語
               原建班欄位（全部要求和預設保留）→ [建立詞庫]
AFTER 空班級：目前班級／來源
               尚無詞語 → [新增詞語] [批次貼上]
               出卷入口及 0 題原因，原表單仍可到達
               批次可展開入口 → 單筆表單 → 空清單下一步
```

空態不是另一套資料或教學步驟。只導向真正可操作的既有表單；出卷功能不以假的示例內容填滿。

### 詞庫：已有詞語／回訪

```text
BEFORE：班級與小型出卷捷徑
         單筆完整表單 → 批次 details → 全部詞語 → 出卷與歷史

AFTER：目前班級／實際資料來源
        [使用此詞庫出卷]  [新增詞語] [批次貼上]
        出卷：課次／題數／實際題池 → [產生考卷與解答]
              進階設定（可收合）／已儲存考卷
        新增區：批次 details → 單筆表單
        班級詞語：課次篩選／詞語數／已核對注音數／編輯與刪除
```

可直達出卷，新增與批次也在班級附近可辨識。沒有固定工具列遮住軟鍵盤或內容的預設承諾；若新增錨點需展開既有 details，只做 DOM 展開／焦點接續，不碰資料。

### 出卷入口與預覽

```text
BEFORE：底部出卷 → 1／8／15 三欄 → 亂數種子 → N 題可抽
         → 產生 → 通知 → 已儲存考卷連結 → exam.html 預覽／列印

AFTER：班級附近的出卷區 → 課次範圍 → 題數與 N 題可抽
        → [產生考卷與解答] → 明確的成功與下一步
        → 最新／既有考卷 [開啟考卷與解答]
        進階：固定抽題設定（原 seed 欄位留在原 form）
        exam.html 預覽／切換考卷或解答／列印：維持原樣
```

已儲存考卷直接重開，不能為了方便而重新抽題。沒有直接前往無 `id` 的 `exam.html` 這種假出卷捷徑。

### 資料保存／同步

```text
BEFORE：三個本機工具連結 → 雲端同步說明 → 家庭帳號
         → 家庭資料（登入後）→ 開發連線設定（環境決定是否顯示）

AFTER：資料保存與同步
        本機：資料留此瀏覽器 → [本機詞庫] [本機備份與還原]
        雲端：同帳號跨裝置 → 現有登入狀態與登入／登出控制
        家庭資料（既有條件顯示）：真實數量／[開啟雲端詞庫]
        既有首次匯入條件及說明／下載雲端備份
        開發連線設定保留原可用性，不變成一般家長的必填教學
```

不是另外做一個同步引擎，也不是合併本機與雲端兩個詞庫。狀態、資料來源和動作放在同一閱讀群組；不用單靠顏色表示成功。

## 風險與止步條件

- **列印繼承**：`exam.html` 載入未限定媒體的 `learning.css`；修改全域字型、行高、main、h2 或 box sizing 都可能改印刷。`@media screen` 也不是 PDF 萬靈丹，首頁 html2canvas 會使用螢幕樣式；因此 selector 及 worksheet 的捕捉祖先也要保持。任何輸出差異即回退該操作區改動，不更改印刷基準。
- **表單移動**：視覺排序不能破壞 form ownership、`elements`、事件綁定、aria 關聯或焦點。種子不可被移出 `#examForm`；單筆／批次不得巢狀 form。新的入口不得引發儲存。
- **來源標籤**：以現有 `cloud` 開啟結果及既有成功分支為真相；不以登入存在或 URL 字串就宣稱資料已同步。不能改 `cloudStorage` 來方便顯示。
- **新手與回訪衝突**：出卷前移可能讓空班級看見不可用題池，故空態先講新增下一步，但保留原可用性與驗證，不新寫題池規則。詞庫數量和可抽題數明確分開。
- **尚無畫面證據**：不得把本計畫的間距、首屏／兩欄安排視為已驗證。先量測再做最小調整；無法取得 Windows／實機結果時照實列缺口，不擴大成全站重設計。
- **範圍**：如果需要改儲存、演算法、Auth、來源資料或 renderer 才能達成某個視覺想法，放棄該做法並另列提案。本次不修相鄰後端功能，不新增匯入管線或登入方式。
