# 首頁下載 PDF 裁切

## 重現

- 在 Windows Chrome 開啟首頁，使用康軒 113 上五年級第 3 課及二年級第 7 課，分別產生一頁和四頁。
- 自訂文字使用「晴天山水花鳥」及「晴天山水花鳥東西南北春夏」，分別產生一頁和兩頁。
- 等候頁面字型與各筆順圖載入，分別下載備份 PDF，並用原生列印存 A4 PDF。將兩種 PDF 逐頁渲染，核對文字、筆順與七排習寫格。
- 修正前，1280 px Chrome 的四組直接下載樣本都將 984 × 2074 像素的影像按 210 mm 寬放入 A4，結果高 442.62 mm。原生列印保留頁數和最後一排，直接下載在習寫區裁掉下方各排。

## 修正與驗證

直接下載在 html2canvas 的副本以 A4 寬度擷取。加入 PDF 時按頁面實際尺寸等比縮放，影像在 A4 內水平置中。原生列印路徑沿用既有設定。

Windows Chrome 156 已驗證 820、1280、1440 px 桌面視窗。每種尺寸跑過自訂文字及康軒課綱的單頁與多頁。另以 1280 px 驗證已確認課次的首頁及其中的自訂入口。原生列印使用 Chrome 列印引擎存檔，iPhone Safari 與實體紙本另行驗收。
