# D-05｜從雲端載入學校教材

家長先選學校使用的出版社，再選學年度、年級、學期及課次。登入開發測試帳號後，載入該帳號獲准查閱的教材。已確認過的進度照原版本恢復；從檔案匯入仍可作為備援。家庭備份只含進度和習寫等個人紀錄，不含教材內容。

## 專用開發環境

2026-11-12，Owner 授權匯入三家教材至專用 Supabase 開發環境。以 `scripts/prepare-curriculum-review.mjs` 核對工作簿和比對報告雜湊，按出版社、年級和課次比對 D-03R 紀錄。康軒 64 課、南一 67 課、翰林 63 課，各六個年級。共 194 課；八筆有差異或無對應的單元仍隔離。只存課次、生字、習寫／認讀分類、核對來源及版本，未匯入課文、課名、Excel 或原始快照。

- `curriculum_internal` 不對 Data API 開放。測試查詢只能透過 `read_review_curriculum`，依已登入使用者 ID 與批次授權；開發環境只授權既有、已連結 Google 的驗收帳號。撤回時從 `review_access` 移除該批次的帳號授權。
- 公開目錄獨立存放經核准的教材和授權依據，目前為空。公開發佈須先通過 [D-04](d-04-curriculum-redistribution.md)。應用程式沒有將測試教材升為公開資料的操作。
- Windows 預覽使用現有 Google 回呼來源 `http://127.0.0.1:8765`。選用的 `cloudConfig.local.mjs` 只放開發端網址及 publishable key，排除於 Git 和 Cloudflare 部署之外。候選資料、匯入 SQL 和驗收輸出放在忽略的 runtime 路徑。

## 驗證

- 真實開發 API：匿名和另一個已登入帳號不能讀取私有教材。既有 Google 連結驗收帳號可讀 18 組、194 課，公開目錄為空。
- 全新 Chrome 桌面及手機尺寸工作階段均無須匯入 JSON。三個出版社都可選課；切換出版社須重選年級，未核對課次有提示。中斷教材請求後可重試。驗收前後家庭備份一致。
- 本輪沒有改動正式站，也未驗收實體 iPhone 上的教材載入。

## 首頁練習簿

已登入家庭帳號時，首頁使用與「國字學習查詢」相同的進度和教材版本。家長尚未設定時，首頁引導選擇出版社。已確認第 8 課時，首頁預設準備第 8 課的習寫字。下拉選單可改練同教材的其他課，選擇只在當次頁面生效。

缺少已確認的教材版本或課次字表時，顯示可採取的操作。手動輸入生字仍可產生練習簿。獨立使用內建資料時，首頁標示康軒 113 學年度。

33 項自動測試通過。使用臨時驗收帳號，手機尺寸 Chrome 在開發端確認合成教材第 8 課，桌面 Chrome 讀回進度並下載一頁 A4 PDF。改練其他課後，雲端備份保持一致。另以既有驗收帳號從開發端讀取實際 115 上翰林教材，驗證未匯入 JSON 也能產生正確習寫字。登出清除畫面，原 113 年版仍可開啟列印並記錄輸出。本輪瀏覽器驗收使用 Windows Chrome。
