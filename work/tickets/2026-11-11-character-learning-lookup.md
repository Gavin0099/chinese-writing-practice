# 國字學習查詢

家長選擇目前的學年度、出版社、年級、學期與課次。可輸入單字、詞語或貼上整段作業文字，逐字查看教材最早收錄的課次、依已確認進度推算的教學狀態，以及孩子的習寫紀錄。拍照辨識加入後，辨識結果走同一套查詢。

| Slice | 交付 | 驗收 |
| --- | --- | --- |
| D-03R～D-05 | 裁決差異、確認授權及接入版本 | 可追溯到工作簿與教育百科，未決或未授權資料不進正式來源。 |
| F-00 | 分離練習紙輸出與教學進度 | 舊設定與練習歷史可讀，預覽和輸出不會建立或修改家長確認的進度。 |
| F-01 | 家長設定教材版本與進度 | 在家長確認前，輸入「目前教到第八課」只提出進度候選。切換教材時須確認新版本的進度。 |
| F-02 | 純逐字查詢核心 | 保留文字中的字位置，回傳可追溯課次、教學狀態及已提供的習寫狀態。 |
| F-03 | 手動查詢介面 | 詞語和整段文字走相同查詢，逐字呈現結果並合併重複字。 |
| F-04 | 記錄習寫狀態 | 能記錄寫錯、漏筆畫、注音代字、家長確認的熟練狀態，並保留各筆紀錄。 |
| OCR-01／OCR-02 | 拍照輸入 | 顯示可修改的辨識文字，從照片提出課次候選，設定進度前由家長確認。 |

老師指定詞語、注音題和組卷由 [V 系列](teacher-vocabulary-worksheets.md) 負責。

## 每個字的三項資訊

- **教材收錄**顯示已驗證教材範圍中最早可查到的課次和後續出現課次，區分習寫與認讀。跨學期或跨出版社時，需有該孩子當期使用的教材資料才能納入。
- **課堂進度**以家長確認的教材與課次判斷。該字在已確認的進度內有已驗證課次時，可顯示「推估已教」。完整教材歷史和進度才能支持「尚未教到」，證據不足時顯示「資料不足」。未編號單元需要另外確認教學進度。
- **孩子的習寫表現**來自練習和家長紀錄。沒有紀錄時顯示「尚無習寫紀錄」，曾經錯寫和目前已熟練可以同時保有各自的日期與證據。

## 優先驗收情境

- 家長選擇康軒二上第八課後輸入「烏雲密布」。頁面依已驗證的教材證據顯示各字的來源，遇到尚未核實的課次或前期缺資料時明確標示。
- 同一個字曾在較早課次以認讀字出現、較後課次才要求習寫。查詢能呈現兩次出現的性質，並保留獨立的孩子習寫紀錄。
- 照片辨識成錯字或把版次認錯時，家長可先修正再查詢。修改辨識文字本身不會改動教學進度或習寫紀錄。
