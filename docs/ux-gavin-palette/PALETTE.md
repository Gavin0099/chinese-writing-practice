# 螢幕 UI 配色：暖紙白 × 沉穩霧藍 × 少量珊瑚橘

本 PR 把 Gavin 指定的配色，套到 PR #8（`ab/cwp-color-b-1112`，`78a1d2b`）已經接受的排版與 `--ui-*` token 上。這不是 skill A/B 的結果，也不是 agent 自行決定的色系。來源是使用者對產品定位的說明：像一本有質感的國語練習簿，操作起來像現代、清楚的 App；不要大面積深綠，也不要兒童粉彩或純藍灰科技風。

**一行配色：暖紙白 `#FAF8F4` ＋ 白卡片 `#FFFFFF` ＋ 霧藍 `#315F8C` ＋ 墨藍黑 `#243444` ＋ 少量珊瑚橘 `#C86D4B`。**

只改螢幕 UI。列印、`exam.css`、田字格、描紅、筆順 SVG、PDF 紙張與所有 `@media print` 區塊都不變。本 PR 也沒有改抽題、資料契約、Auth 或同步邏輯。

## 1. Gavin 指定的色票與用法

| UI 元素 | 顏色 | 色碼 |
| --- | --- | --- |
| 頁面背景 | 暖紙白 | `#FAF8F4` |
| 卡片、輸入欄位 | 白 | `#FFFFFF` |
| 主要按鈕、主要連結 | 霧藍 | `#315F8C` |
| 按鈕 Hover | 深藍 | `#244A72` |

| 重要提示、里程碑裝飾 | 珊瑚橘 | `#C86D4B` |
| 暖色小字 | 深陶土 | `#A95133` |
| 正文、標題 | 墨藍黑 | `#243444` |
| 次要文字 | 藍灰 | `#566675` |
| 輸入框邊線 | 中性藍灰 | `#71879A` |
| 成功狀態 | 可保留綠色，但必須搭配文字或圖示 | — |

他計算、本次重算也一致的對比：

| 配對 | 所述 | 本次 sRGB 計算 |
| --- | ---: | ---: |
| 主要按鈕白字／霧藍底 `#FFFFFF / #315F8C` | 6.67:1 | 6.67:1 |
| 次要文字／白底 `#566675 / #FFFFFF` | 5.91:1 | 5.91:1 |

珊瑚橘對白底約 3.66:1，只適合大字、裝飾或非文字 UI，不當一般小字。因此提示小字用陶土，里程碑大標題才用珊瑚橘。

### 本 PR 新增的強調 token

既有 20 個 token 沒有「珊瑚橘強調」或「暖色小字」的獨立角色。若不新增，珊瑚橘只會出現在焦點環上。

| Token | 新值 | 用途 | 來源 |
| --- | --- | --- | --- |
| `--ui-accent` | `#C86D4B` | 成功態大標題「練習簿已準備好」、詞庫 `#storageNotice` 左側裝飾（`box-shadow`，不改變版面） | Gavin 指定 |
| `--ui-accent-text` | `#A95133` | 首頁 `.hero-hint`、LINE 引導小字 | Gavin 指定 |

一般說明和表單 `.hint` 仍用 `--ui-muted`，避免整頁都偏橘。成功態的 ✅ 表情符號本身是綠的，並搭配標題文字，符合「成功可保留綠色，但必須搭配文字或圖示」。

## 3. 同時修正的舊色（只改呈現，不改邏輯）

完整盤點見 PR 說明。本 PR 實際改動：

- 四頁既有的 `theme-color` 由 `#f6f8f3` 改為 `#FAF8F4`；首頁與國字查詢頁補上同一值。
- 頁尾內嵌樣式的舊成功綠 `#166534`／`#f0fdf4`／`#bbf7d0`，以及舊灰藍／回饋藍，改為 `var(--ui-*)`。
- `script.js` 只改色碼字面值，見下一節。

**沒有改：** 筆順 SVG `fill="#000000"`、教材藍 `#3B4CCA`、`stroke_renderer_new.js`、`exam.css`、任何 `@media print`、任何 JS 控制流程。
