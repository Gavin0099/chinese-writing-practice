# 教育部標準字體下載指引

## 📥 下載步驟

### 方法 1: 教育部官方網站

1. **訪問教育部語文成果網**
   ```
   https://language.moe.gov.tw/001/Upload/Files/site_content/M0001/edukai-4.0.zip
   ```

2. **下載檔案**
   - 檔案名稱: `edukai-4.0.zip`
   - 大小: 約 12 MB
   - 包含: `edukai-4.ttf`

3. **解壓縮**
   - 解壓後得到 `edukai-4.ttf`

### 方法 2: 全字庫網站

1. **訪問全字庫**
   ```
   https://www.cns11643.gov.tw/wordView.jsp?ID=66314
   ```

2. **下載字型**
   - 選擇「楷書」
   - 下載 `TW-Kai-98_1.ttf`

---

## 📋 下載後的步驟

### 1. 將字體檔案放入專案

```
chinese-writing-practice/
```
