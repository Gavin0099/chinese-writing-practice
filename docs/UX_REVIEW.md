# UX／UI 審查入口

使用本分支的程式碼進行評估。用乾淨的瀏覽器設定檔看首次使用，再載入合成資料看日常操作。準備 Node.js 22 與 Python 3.10 以上後，在儲存庫根目錄執行：

```sh
node scripts/create-ux-review-fixtures.mjs
python scripts/preview.py
```

開啟 [本機首頁](http://127.0.0.1:8765/)。合成檔案位於 `artifacts/runtime/ux-review/`，可直接透過網頁的檔案選擇器載入。

| 場景 | 試用方法 |
| --- | --- |
| 首次使用 | 從首頁找出國字查詢、老師詞庫、備份和雲端同步入口，記下哪一步需要猜測下一步。 |
| 查國字與記錄習寫 | 在「國字學習查詢」從檔案同時匯入 `sample-candidate.json` 和 `sample-comparison.json`。先選「合成教材」，選第 1 課並確認進度，輸入「春雨傘」查詢，再記錄一筆習寫狀態。合成教材的來源連結僅供測試。 |
| 首頁練習簿 | 回到首頁，確認顯示「合成教材」第 1 課，並產生含「春」的練習簿。切換到第 2 課，確認畫面說明本課沒有習寫字。重新整理應回到已確認的第 1 課。 |
| 詞庫到考卷 | 在「備份與還原」選取 `sample-backup.json`，預覽並還原到空白的測試設定檔。到「老師詞庫與出卷」選示範班，第 1 至第 2 課抽 15 題，開啟考卷、解答與列印預覽。 |
| 帳號與同步 | 在「雲端同步」看未設定與未登入的入口提示，並檢查從詞庫或學習紀錄進入時，能否理解本機與雲端的差別。實際登入需另接審查者自己的 Supabase 測試專案。 |

要試雲端教材自動載入，請在自己的 Supabase 測試專案套用本分支的 migrations，再執行產生的 `sample-catalog.sql`。從「雲端同步」設定專案並登入，開啟雲端學習紀錄，確認「合成教材」第 1 課後回到首頁。第二個乾淨的瀏覽器設定檔以同一帳號登入，應直接看到第 1 課，無須匯入 JSON。這個流程使用合成字表。

請用桌面和手機寬度各走一次。優先回報會中斷任務或讓家長選錯的問題，附入口、重現步驟、畫面和建議的下一步。視覺意見可分開記錄排版層次、主要按鈕、字級與留白。
